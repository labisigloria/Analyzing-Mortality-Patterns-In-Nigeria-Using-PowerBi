# Analyzing-Mortality-Patterns-In-Nigeria-Using-PowerBi
This project focuses on analyzing a world health organization data that shows mortality pattern in Nigeria across the year 1990 to 2020.
# Project Overview
This project analyzes mortality patterns and leading causes of death in Nigeria using Power BI. The goal of the analysis was to explore disease burden trends, identify major causes of mortality, and demonstrate how healthcare data can be transformed into meaningful insights through data visualization and analytics.
The project combines healthcare analysis with data storytelling, reflecting an interest in Health Informatics and public health analytics.
# Objectives
The main objectives of this project were to:
*	Analyze mortality trends in Nigeria from 1990–2020
*	Identify the leading causes of death
* Compare communicable and non-communicable disease burdens
*	Build an interactive dashboard using Power BI
*	Derive meaningful public health insights from healthcare data
# Tools and Technologies Used
*	Microsoft Power BI
*	Power Query
*	DAX Measures
*	Data Visualization Techniques

The dataset underwent several preprocessing steps before analysis, including:

* Removing null and empty values
* Checking for inconsistencies and duplicates
* Formatting columns correctly
* Creating disease category classifications
* Grouping diseases into:
   * Communicable diseases
   * Non-communicable diseases
  * Others

Additional DAX measures were created to calculate:
* Total deaths
* Leading cause of death
* Disease burden percentages
* Mortality trends over time
# Dashboard Features
The dashboard includes:
*	Total deaths KPI
*	Leading cause of death analysis
*	Mortality trend analysis over time
*	Disease burden distribution
*	Top causes of death visualization
* Interactive filters for year and disease selection
# Key Insights	
*	Communicable diseases accounted for the highest mortality burden in Nigeria, contributing approximately 25.4 million deaths.
*	Diarrheal diseases emerged as the leading cause of death among the diseases analyzed.
*	Mortality rates increased steadily during the 1990s and early 2000s, peaking around 2005–2008 before gradually declining afterward.
*	Non-communicable diseases also contributed significantly to mortality, highlighting the growing burden of chronic diseases.
